## Instalación técnica

Los SVG son mockups y recursos de diseño. Para una ISO real hay que convertirlos y registrarlos en los sistemas correspondientes:

- **Plymouth:** tema de arranque y animación.
- **SDDM:** tema de login de KDE.
- **Plasma:** fondo y configuración del escritorio.
- **ISO:** copia de recursos a `/usr/share` mediante un paquete o overlay.

No se puede generar una ISO ni mostrar una captura real desde GitHub sin ejecutar el proceso de compilación; los SVG permiten revisar el diseño inmediatamente en el navegador.
